# Yevqo platform subscriptions

These are platform subscriptions, separate from any future Hosting/provider plans.

| Plan | Price | Current entitlement |
|---|---:|---|
| Free | €0/month | One connected Android Agent; core project and deployment features |
| Pro | €5.99/month | Unlimited connected Android Agents and Yevqo REST API/API keys |
| Advanced | €10.99/month | Includes Pro; planned expanded Agent Network, analytics, automation, security capabilities and higher resource limits |

Advanced is represented as a distinct account status and currently inherits Pro's API and device entitlements. Its additional capabilities must only be advertised as active after their corresponding modules and limits are implemented and verified.

## Billing status

Checkout, recurring payments, invoices, cancellation and automatic plan activation are not implemented. Until a billing provider is integrated, an administrator assigns Free, Pro or Advanced manually from Admin → Users → user details. The profile page displays the plans and clearly states this limitation.

The primary administrator retains unlimited access. Blocked accounts remain blocked regardless of plan assignment.
